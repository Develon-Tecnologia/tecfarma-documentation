Novidades da versão 2026.08.09

Release Notes — tudo que foi entregue neste ciclo

Período coberto: 15/06/2026 a 10/08/2026  ·  Versão: 2026.08.09  ·  Itens entregues: 26 novidades + 24 correções = 50 itens

⭐ Destaques desta versão

  • TEC-2114 — Zeus 2026.7.16: biblioteca Zeus NFe/NFCe atualizada para a versão 2026.7.16.1250, base para todos os novos recursos fiscais.
  • TEC-1870 — NF-e via Zeus: emissão de NF-e completa pelo componente Zeus, integrada à nova reforma tributária (IBS/CBS).
  • TEC-796 — Cancelamento de NF-e pelo Histórico: botão de cancelamento disponível diretamente na tela de Histórico de Notas Fiscais, sem precisar abrir outra tela.
  • TEC-2116 — Rejeição 232 corrigida: IE do destinatário vazia, isenta ou zerada agora é tratada automaticamente como não-contribuinte, eliminando rejeições em série.
  • TEC-2111 — Imendes API 3.0: integração com a plataforma Imendes migrada para a API 3.0, mantendo retrocompatibilidade com os fluxos existentes.

✨ Novidades Adicionado

Reforma Tributária / Zeus

  • TEC-2114 Zeus NFe/NFCe 2026.7.16 — biblioteca Zeus atualizada para a versão 2026.7.16.1250, com suporte completo à nova reforma tributária (IBS/CBS/IS). Fundação para TEC-1870 e TEC-2113. PR #931
  • TEC-1870 NF-e — Emissão via Zeus — implementação da criação da NF-e pelo componente Zeus para a nova reforma tributária. NF-e agora gera todos os campos IBS/CBS exigidos pelo SEFAZ. PR #915
  • TEC-2113 NF-e — Guia Reforma Tributária — guia "Reforma Tributária" exibida na tela de emissão de NF-e quando o Zeus está configurado, facilitando o preenchimento dos campos IBS/CBS. PR #930

NF-e

  • TEC-796 NF-e — Cancelamento pelo Histórico — botão de cancelamento de NF-e disponível diretamente na tela de Histórico de Notas Fiscais Eletrônicas, eliminando a necessidade de navegar para outra tela. PR #918
  • TEC-793 NF-e — XML de cancelamento armazenado — XML do evento de cancelamento da NF-e agora é persistido no banco de dados, garantindo rastreabilidade completa. Aplicado na Retaguarda nova e antiga (port). PR #866, #892
  • TEC-2067 NF-e — Relatório de emissão própria — novo relatório de produtos lançados em NF-e de emissão própria, com linha de filtro digitável para busca rápida por produto ou fornecedor. PR #911, #914
  • TEC-1913 NF-e / NFC-e — CNAE do emitente — CNAE da empresa emitente incluído no XML da NF-e e NFC-e conforme exigência fiscal. Aplicado na Retaguarda nova e antiga (port). PR #871, #893, #895
  • TEC-1321 NF-e — CRUD notaFiscalxArquivoXml — novo CRUD para gerenciar os arquivos XML vinculados às notas fiscais, permitindo rastreamento e consulta dos XMLs armazenados. PR #858
  • NF-e Série de emissão e numeração por série — NF-e agora armazena a série de emissão e controla a numeração separadamente por série, evitando conflitos em ambientes com múltiplas séries configuradas. PR #856

NFC-e / PDV

  • TEC-2089 NFC-e — Correção de inconsistências em 2º plano — correção automática de NFC-e em segundo plano após a emissão (cStat 611/374/382/725), gateada por configuração. Evita interrupção do fluxo de venda no PDV. PR #899
  • TEC-2092 NFC-e — Sincronização com correção de inconsistências — a sincronização agora respeita a configuração "Corrigir Inconsistências", unificando o comportamento entre emissão e sincronização. PR #897
  • TEC-2087 PBM Funcional — Meio de pagamento no parcial — operador pode agora definir o meio de pagamento no pagamento parcial do PBM Funcional, com os meios "à vista" preservados corretamente. PR #886, #888

Retaguarda / Operações

  • TEC-2111 Imendes — API 3.0 — integração Imendes migrada para a API 3.0 (endpoint api/v3), compatível com o novo modelo de saneamento de grades e regras fiscais. PR #923
  • TEC-2102 Retaguarda — Comissão por Funcionário — relatório de Comissão por Funcionário agora exibe o total por funcionário, com subtotais por produto. Corrigida também exceção RuntimeBinderException em campos nulos. PR #909, #919
  • TEC-2107 Pré-Venda — Número único garantido — unicidade do número da pré-venda garantida por validação no banco, eliminando duplicações causadas por concorrência (race condition). PR #913
  • TEC-2101 Estoque — Validação fiscal por filtro — validação dos dados fiscais ao confirmar operações por filtro de cClassTrib em Operação por Filtro, evitando emissão com classificação tributária inválida. PR #908
  • TEC-2081 Receituário — Data Receita opcional — nova configuração permite deixar o campo "Data Receita" em branco no receituário de produto controlado, atendendo farmácias com fluxo simplificado. PR #910
  • TEC-638 Empresa — Bloqueio com NFC-e pendente — cadastro da empresa bloqueado quando há NFC-e pendente de transmissão, prevenindo alterações que invalidariam notas em fila. Aplicado na Retaguarda nova e antiga (port). PR #867, #890
  • TEC-671 Produto — Lote no histórico de movimentação — lote vendido agora exibido no histórico de movimentação do produto, facilitando rastreabilidade de lotes e conferência de estoque. PR #916
  • TEC-683 Produto — Preço inicial no histórico — ao cadastrar um novo produto, o preço inicial é registrado automaticamente no histórico de preços, garantindo rastreabilidade desde o primeiro cadastro. PR #865
  • TEC-1653 Entrada NF — Coluna Promoção — coluna "Promoção (R$)" adicionada à esquerda do PMC na tela de atualização de preços na entrada de NF, tornando a comparação com o preço promocional imediata. PR #879
  • TEC-2057 Entrada NF — Custo e validade — NotaFiscalxProduto_Registrar agora persiste data de fabricação/validade e retorna o custo unitário calculado, alimentando corretamente o histórico de custos na entrada. PR #869, #907
  • TEC-2069 Plataforma — Preço do produto — preço do produto enviado para a plataforma integrada, mantendo o catálogo sincronizado com os preços praticados no PDV. PR #889
  • TEC-1863 Performance — Índice ProdutoxTributo — índice criado na tabela ProdutoxTributo, reduzindo o tempo de consultas fiscais por produto em bases com grande volume de registros. PR #929
  • TEC-2076 PBM — Receita do controlado — receita do medicamento controlado pode ser definida diretamente no PBM, evitando solicitação dupla ao operador durante o fluxo de venda. PR #840
  • TEC-2056 Retaguarda — Relatórios RMNRA / RMNRB — mensagem informativa exibida nos relatórios RMNRA e RMNRB quando não há movimentação no período selecionado, evitando confusão com relatórios em branco. PR #835
  • TEC-2066 Retaguarda — Bloqueio CFOP 5929 — emissão de NF-e com CFOP 5929 bloqueada na Retaguarda, prevenindo emissões com natureza de operação indevida para o tipo de venda. PR #838

🛠️ Correções Corrigido

NF-e

  • TEC-2116 NF-e — Rejeição 232 (IE do destinatário) — IE do destinatário vazia, isenta ou zerada agora tratada automaticamente como não-contribuinte, corrigindo rejeições em série na emissão de NF-e para PF ou empresas isentas. PR #932
  • TEC-2093 NF-e — CFOP validado antes da emissão — CFOP validado antes de iniciar a emissão da NF-e; alteração de NF-e de saída já autorizada bloqueada, prevenindo inconsistências fiscais. PR #900
  • TEC-1773 NF-e — xJust no XML de cancelamento — justificativa (xJust) incluída corretamente no XML de cancelamento arquivado, garantindo conformidade com o schema SEFAZ. PR #874
  • TEC-2078 NF-e — Campos da transportadora — campos da transportadora (nome, CNPJ, endereço) que não estavam sendo salvos no XML da NF-e agora persistidos corretamente. PR #842
  • TEC-1761 NF-e — Formatação ANTT e pesos — Código ANTT, UF da placa e campos de pesos (bruto/líquido) formatados corretamente na emissão da NF-e, evitando rejeição por formato inválido. PR #876

NFC-e / PDV

  • TEC-2100 NFC-e — Rejeição na retransmissão — corrigida rejeição de pagamentos na retransmissão de NFC-e e exceção na tela de correção de pendentes, estabilizando o fluxo de recuperação de notas rejeitadas. PR #912
  • TEC-2097 NFC-e — Tabela NFCeProduto alimentada — tabela NFCeProduto alimentada corretamente após a criação do XML na correção de inconsistências, corrigindo divergências nos relatórios de NFCe por produto. PR #904
  • TEC-2091 NFC-e — Sincronização e arquivoXML_url — arquivoXML_url atualizado corretamente após a autorização; NFC-e já autorizada não mais relançada como erro na sincronização automática. PR #903
  • TEC-2094 NFC-e — Divergência em relatórios contábeis — divergência nos totais dos relatórios contábeis da NFC-e corrigida, garantindo conciliação correta entre o sistema e a contabilidade. PR #902
  • TEC-2096 NFC-e — TransmitirContingências limitado — transmissão de contingências limitada a 1 execução por dia quando a configuração de correção de inconsistências está ativa, evitando sobrecarga no SEFAZ. PR #901
  • TEC-2090 NFC-e — Cód. Barras Secundário na Gerar Venda — ferramenta "Gerar Venda" agora reconhece o Código de Barras Secundário do produto, eliminando falha ao usar produtos com código alternativo. PR #896
  • TEC-1912 NFC-e — cStat 374 CFOP incompatível — correção local para NFC-e rejeitada com cStat 374 (CFOP incompatível com o destinatário), reprocessando com CFOP ajustado automaticamente. PR #870
  • TEC-1740 NFC-e — CST X40 por dígito de origem — roteamento do CST X40 pelo dígito de origem corrigido no emissor via API, resolvendo inconsistência tributária em produtos com tributação monofásica. PR #877
  • TEC-2023 NFC-e — PBM desconto em folha como DINHEIRO — venda de PBM com desconto em folha não mais registrada como "DINHEIRO" no fechamento da NFC-e, corrigindo o meio de pagamento transmitido ao SEFAZ. PR #837, #854
  • TEC-2088 PBM / Funcional — ValorOperadora negativo — ValorOperadora negativo quando ValorPagarAVista > 0 corrigido; valor agora persistido corretamente na NFC-e do Funcional Card. PR #881, #884, #885
  • TEC-2074 Pré-Venda — PBM com controlado — erro ao finalizar venda de PBM quando o carrinho continha produto controlado corrigido, eliminando exceção que travava o PDV. PR #836
  • TEC-2109 ECF — Menu Sua Receita Digital removido — menu "Sua Receita Digital" retirado da tela de Digitalização do ECF, que estava sendo exibido indevidamente nesse contexto. PR #921
  • NFC-e / PDV Consistência Vendas × VendasxProdutos — validação de consistência entre as tabelas Vendas e VendasxProdutos executada antes de criar a NFC-e; venda divergente reconstruída a partir da Pré-Venda automaticamente. PR #898

SPED Fiscal

  • TEC-1768 SPED — Registro C190 da NFC-e — registro C190 do SPED Fiscal gerado a partir da tabela NFCexProduto, corrigindo inconsistência nas saídas de NFC-e no arquivo fiscal. PR #875
  • TEC-2075 NFC-e — Relatório de NCM — divergências no Relatório de NCM da NFC-e corrigidas; totais por NCM agora conciliam com os valores transmitidos ao SEFAZ. PR #841, #853

Retaguarda / Operações

  • TEC-1826 Estoque — Divergência com histórico — divergência entre o estoque atual e o histórico de movimentação corrigida, garantindo que o saldo exibido reflita todas as entradas e saídas registradas. PR #873
  • TEC-1831 Retaguarda — Importação CSV com quebra de linha — quebra de linha incorreta na importação de CSV de produtos corrigida; linhas com descrições longas agora importadas sem truncamento ou fusão. PR #872
  • TEC-1405 Caixa — "Caixa Fechado" falso positivo — mensagem "Caixa Fechado" exibida incorretamente com caixa aberto corrigida; estado do caixa verificado diretamente no banco antes de exibir o alerta. PR #868
  • TEC-1287 Produto — Código duplicado eliminado — race condition MAX(codigo)+1 que gerava códigos de produto duplicados em cadastros simultâneos eliminada com lock de banco. PR #864
  • TEC-2004 Atualizador — SCHEMA completo — publicação de versão agora sobe o SCHEMA com todos os arquivos necessários, corrigindo instalações que ficavam incompletas após a atualização. PR #863
  • TEC-2086 Atualizador — Migração FTP → API — FTP removido do atualizador; publicação de versão migrada para a API cloud-varejo-hub. Corrigidos também: ternário invertido no download e validação de urlAzure inválida antes de publicar. PR #862, #882, #883
  • Atualizador Upload de versão — Exceção real exposta — erro real exibido no log quando o upload de versão falha, substituindo mensagem genérica que dificultava o diagnóstico. PR #926
  • Farmácia Popular Timeout do servidor — Mensagem orientativa — mensagem de timeout do servidor Farmácia Popular atualizada para orientar o operador sobre falha de internet, reduzindo chamados de suporte por erro de conexão. PR #891
