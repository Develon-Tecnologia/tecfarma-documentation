Como configurar a iMendes em uma nova Drogaria

Guia passo a passo para o Suporte Técnico habilitar a integração iMendes em uma farmácia recém-contratada.

Visão Geral

A integração iMendes (LabFisc — consultatributos.com.br) é o serviço de saneamento fiscal do Tecfarma. Ela consulta regras tributárias (NCM, CEST, CST, CSOSN, alíquotas PIS/COFINS/ICMS, CFOP) para os produtos cadastrados na drogaria e atualiza os campos fiscais automaticamente.

A integração é controlada por dois pontos de configuração distintos:

  • Tabela Imendes — dados fiscais da drogaria (regime, CRT, CNAE, ambiente). Preenchida via tela de configuração no Retaguarda.
  • Tabela Configuracao — chaves de comportamento automático (aplicar regras após entrada de NF, após salvar produto).
Autenticação: O Tecfarma autentica na API iMendes usando credenciais de parceiro da Develon (hardcoded no sistema). O CNPJ da drogaria é verificado via endpoint GetStatusCliente — a drogaria precisa estar previamente contratada com a iMendes/LabFisc.

Pré-requisitos

  1. Contrato ativo com a iMendes (LabFisc) — o CNPJ da drogaria deve estar habilitado no sistema iMendes antes de qualquer configuração no Tecfarma.
    Contato iMendes: (35) 9870-9462 · financeiro@labfisc.com.br [FrmImendesPainel.cs:1053]
  2. Cadastro da Empresa preenchido — a farmácia deve ter CNPJ, UF e Regime Tributário definidos na tela Cadastro → Empresa antes de abrir a configuração iMendes.
  3. Acesso de Suporte — a tela de configuração iMendes exige login de Suporte Técnico (credenciais do colaborador de suporte).
  4. Conectividade HTTP — o servidor Tecfarma precisa acessar http://consultatributos.com.br:8080/ na porta 8080.

Passo a Passo — Configurar iMendes em uma Nova Drogaria

  1. Confirmar contrato ativo com a iMendes Antes de qualquer configuração, verifique com a LabFisc se o CNPJ da drogaria está habilitado: ligue para (35) 9870-9462 ou envie e-mail para financeiro@labfisc.com.br. Sem contrato ativo, o botão de consulta ficará bloqueado com a mensagem "Consulta impedida".
  2. Verificar cadastro da Empresa No Retaguarda, acesse Cadastro → Empresa e confirme que CNPJ, UF e Regime Tributário estão preenchidos corretamente (Simples Nacional / Lucro Presumido / Lucro Real). O regime tributário da iMendes deve coincidir com o do cadastro Empresa — o sistema bloqueia caso haja divergência.
  3. Abrir a tela de configuração iMendes No menu principal do Retaguarda, localize o botão iMendes Configuração (brbtniMendesConfiguracao). O sistema solicitará as credenciais do Suporte Técnico. Após autenticar, abrirá a tela FrmImendesConfiguracao_Cadastro. [FrmPrincipal.cs:10419–10446]
  4. Preencher os campos obrigatórios
    Campo na telaO que preencher
    Regime TributárioSelecione igual ao cadastro da Empresa (bloqueado se já igual)
    CRTSimples Nacional → 1 · Lucro Presumido/Real → 3
    CNAE7 dígitos. Para farmácias/drogarias varejistas: 4771701
    AmbienteSelecione 2 - PRODUÇÃO (produção real) ou 1 - HOMOLOGAÇÃO para testes
    Contribuinte do ICMSNormalmente 0 - Não Contribuinte para farmácias Simples Nacional
    Código Faixa EnquadramentoDeixar vazio para Simples Nacional · 99 para Lucro Real · 98 para Lucro Presumido
    Regime EspecialDeixar vazio (preencher somente se a drogaria tiver regime especial estadual)
  5. Salvar a configuração Clique em Salvar. O sistema grava na tabela Imendes (INSERT se primeira vez, UPDATE se já existia). Um registro na tabela com ambiente ≠ "0" e cnae preenchido é o que habilita as operações iMendes. [NTecfarma.Imendes.CRUD.cs:139–191 · Imendes_ServicoAtivo:420–436]
  6. Testar conectividade — verificar status do cliente Acesse o Painel iMendes (menu Fiscal → iMendes). O sistema chama automaticamente GetStatusCliente/{cnpj}. Se retornar sucesso, os botões de consulta ficam habilitados. Se aparecer mensagem de erro, verifique o contrato com a LabFisc. [FrmImendesPainel.cs:1026–1075 · Simulador.cs:213–247]
  7. Realizar a primeira consulta em lote No Painel iMendes, aba Consulta em Lote: adicione produtos manualmente ou use o botão "Produtos Alterados" para carregar produtos com regras fiscais pendentes. Clique em Confirmar Consulta para enviar ao servidor iMendes. Após retorno, clique em Aplicar Correções para atualizar NCM, CEST, CST, CSOSN, alíquotas no banco de dados.
  8. (Opcional) Habilitar aplicação automática Para que a iMendes corrija automaticamente os produtos em eventos futuros, configure as chaves na tabela Configuracao:

    CONFIGURACAO_APLICATIVO_IMENDES_CORRIGIRAPOSENTRADANOTA = true — aplica após entrada de NF de compra
    CONFIGURACAO_APLICATIVO_IMENDES_CORRIGIRAPOSCADASTRARPRODUTO = true — aplica após salvar produto [ChaveConfiguracao.PBM.BIG.cs:19–20]

Autenticação na API

Todas as chamadas usam headers HTTP login e senha. O sistema usa as credenciais de parceiro da Develon (hardcoded em NTecfarma.Imendes.Simulador.cs:12–13), não as credenciais da drogaria:

ImendesParceiroLogin = "07195280000180"   // CNPJ Develon (parceiro)
ImendesParceiroSenha = "vUBRE7t5jGTB"

O CNPJ da drogaria é enviado no body da requisição para verificação de contrato — não no header de autenticação.

Troubleshooting Comum

❌ "O serviço de atualização de tributos iMendes não foi configurado."
Causa: A tabela Imendes está vazia (nenhum registro). Solução: Execute o passo a passo acima para preencher e salvar a configuração. [CRUD.cs:394–400]
❌ "Não foi definido o CNAE na configuração iMendes."
Causa: Campo cnae vazio na tabela Imendes. Solução: Abra a configuração iMendes e preencha o CNAE com 7 dígitos. Para farmácias varejistas, use 4771701. [CRUD.cs:420–427]
❌ "Serviço iMendes não contratado."
Causa: Campo ambiente = "0" (Não Contratado). Solução: Altere o Ambiente para 2 - PRODUÇÃO na tela de configuração. [CRUD.cs:428–435]
❌ "Consulta impedida" no Painel iMendes
Causa: O CNPJ da drogaria não está ativo/contratado na iMendes. Solução: Entre em contato com a LabFisc: (35) 9870-9462 · financeiro@labfisc.com.br. [FrmImendesPainel.cs:1050–1054]
❌ "Regime Tributário deve ser [X]." ao salvar configuração
Causa: O Regime Tributário selecionado na configuração iMendes diverge do campo REGIME_TRIBUTARIO na tabela farmacias. Solução: Verifique o regime no Cadastro → Empresa e selecione o mesmo na configuração iMendes. [FrmImendesConfiguracao_Cadastro.cs:170–188]
❌ "CRT incoerente com o Regime Tributário."
Causa: Simples Nacional exige CRT 1 ou 2; Lucro Presumido/Real exige CRT 3. Solução: Ajuste o CRT conforme o regime. [FrmImendesConfiguracao_Cadastro.cs:176–198]
❌ "Instabilidade na comunicação entre o tecfarma e o serviço iMendes."
Causa: Timeout ou erro HTTP na chamada para http://consultatributos.com.br:8080/. O sistema tenta 3 vezes com intervalo de 2 segundos. Solução: Verifique conectividade de rede/firewall na porta 8080. Tente novamente mais tarde. [CRUD.cs:469–506 · FrmImendesPainel.cs:363–388]
⚠ Produtos não têm NCM/CEST/CST atualizados mesmo após consulta
Causa: A consulta retornou resultados, mas o botão Aplicar Correções não foi clicado. Solução: No Painel iMendes, após a consulta retornar, clique em Aplicar Correções para gravar os dados no banco. [FrmImendesPainel.cs:814–839 · CRUD.cs:285–385]
